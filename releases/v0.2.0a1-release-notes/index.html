    Animora v0.2.0a1 — Pre-Release Notes

    Release Tag: v0.2.0a1
    Release Name: Animora v0.2.0a1 — AI & Machine Learning Visualization Suite (Alpha 1)
    Release Type: Pre-release
    Date: September 3, 2026

    🚀 Overview & Highlights

    Animora v0.2.0a1 is our first alpha pre-release for the upcoming v0.2.0 milestone, introducing the AI & Machine Learning Visualization Suite (Phase 13a through 13e).

    Every algorithm in this release is built upon pure NumPy mathematical foundations—completely free from heavy dependencies on PyTorch, TensorFlow, or NLP runtimes—while maintaining our signature One-Call declarative API (self.play(*algorithm(...))) for cinematic Manim animations.

    📦 What's New in v0.2.0a1

    1. 📐 Mathematical Foundations & Optimization (animora.ml)

    • SurfacePlot: Continuous 2D contour map elevations and iso-level curves for arbitrary scalar loss landscapes $f(x, y)$.
    • VectorField: Directional flow vector field and gradient arrows $-\nabla f(x, y)$ over a regular 2D grid.
    • TensorGrid: Interactive matrix and tensor heatmap visualizer with cell styling, value labels, and highlight animations.
    • gradient_descent: One-call numerical optimization engine on 2D loss surfaces with full diagnostic trajectory tracing.
    • MLComponent, MLTrace, MLTraceStep: Base contracts establishing pure numerical computation isolated from animation choreography.

    2. 📊 Classic Machine Learning (animora.ml.classic)

    • linear_regression: Analytical least-squares fit $(X^T X)^{-1} X^T y$ with dynamic line tracking during gradient descent.
    • logistic_regression: Binary cross-entropy classifier displaying sigmoid probabilities and decision boundary $w^T x + b = 0$.
    • kmeans: Lloyd's clustering algorithm with centroid relocation and Voronoi recoloring across iterations.
    • decision_tree: Recursive Gini impurity and Shannon entropy tree partitioning visualized with TreeLayout and Panel cards.
    • svm: Hard-margin support vector machine with separating hyperplane $w \cdot x + b = 0$, dashed margin boundaries $w \cdot x + b = \pm 1$, and support vector highlights.
    • pca: Covariance eigendecomposition via numpy.linalg.eigh, drawing principal eigenvectors from the centroid and projecting samples orthogonally.

    3. 🧠 Deep Learning & Gradient Flow (animora.ml.deep_learning)

    • neural_network_forward: Multi-layer perceptron architecture with animated activations propagating layer-by-layer.
    • backpropagation: Analytical gradient computation ($\partial \mathcal{L}/\partial W$, $\partial \mathcal{L}/\partial b$) verified against finite differences ($2.28 \times 10^{-11}$ relative error) with reverse gradient wave animation.
    • optimizers (sgd, momentum, adam): Trajectory comparison demonstrating momentum inertia and adaptive moment dynamics over anisotropic loss valleys.
    • cnn_convolution: 2D sliding-window convolution operation showing kernel dot products populating feature map cells.
    • rnn_forward: Unrolled recurrent neural network cell showing the hidden state recurrence relation $h_t = \tanh(W_{xh} x_t + W_{hh} h_{t-1} + b_h)$.

    4. 📖 NLP & Attention Mechanisms (animora.ml.nlp)

    • tokenize: Regex tokenizer extracting tokens and character spans, animating raw strings resolving into bordered badge chips.
    • word_embeddings: Illustrative $D$-dimensional embedding table with 2D PCA projection reuse.
    • attention: Scaled dot-product attention $\text{softmax}(Q K^T / \sqrt{d_k}) V$ with mathematically verified row-wise normalization ($1.0 \pm 10^{-6}$).
    • transformer_block: Minimal single-head attention and ReLU feedforward network composition with transparent pedagogical scope.

    5. 🌐 Documentation Site & Cross-Device Polish (Phases 10.5 & 13e)

    • Dedicated Top-Level Nav: "AI & Machine Learning" is now a primary section in the documentation navigation.
    • Sequential Learning Path: 4-stage guide (Foundations $\rightarrow$ Classic ML $\rightarrow$ Deep Learning $\rightarrow$ NLP/Attention).
    • 19 Responsive SVG Vector Assets: Preview graphics in docs/assets/media/ that scale smoothly on every device (mobile, tablet, desktop, 4K displays).
    • Cross-Device CSS: Responsive media queries in docs/stylesheets/extra.css ensuring fluid layout without overflow.
    • Full API Reference: Section 8 added to docs/reference/api.md covering all new models, visualizers, and functions with zero undocumented symbols.
    • Four New Runnable Examples:
    • examples/08_ai_ml_foundations.py
    • examples/09_classic_machine_learning.py
    • examples/10_deep_learning_and_backprop.py
    • examples/11_nlp_and_attention.py

    🛠️ Installation & Testing

    To test this pre-release from PyPI once published:

    # Install the pre-release specifically
pip install --pre animora

# Or specify the exact alpha version
pip install animora==0.2.0a1

    ⚠️ Notes for Early Testers

    • This is an Alpha pre-release (0.2.0a1) intended for early feedback on the AI/ML visualization APIs.
    • The word embedding table is illustrative for pedagogical clarity and does not represent pretrained semantic embeddings.
    • The transformer block is scoped to single-head attention without layer normalization or residual bypasses to maintain visual clarity for learners.
