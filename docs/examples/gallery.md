# Example Gallery

A curated collection of complete, runnable example scenes demonstrating Animora's capabilities. All example files are located under `examples/` in the repository root.

---

## 1. Visual Primitives & Panels
- **File**: `examples/01_basics_and_shapes.py`
- **Focus**: `Text`, `Shape.circle`, `Shape.rounded_rectangle`, `Panel`, and semantic animations (`animate_fade_in`, `animate_create`, `animate_highlight`).

## 2. Layout Solvers & Grouping
- **File**: `examples/02_layout_and_grouping.py`
- **Focus**: Positioning components via `GridLayout` and `CircularLayout` using `Group.arrange()`.

## 3. Themes & Styling Scoping
- **File**: `examples/03_themes_and_styling.py`
- **Focus**: Using `PaperLight` and `Cyberpunk` themes side-by-side using `with use_theme()`.

## 4. Data Visualization Charts
- **File**: `examples/04_dataviz_charts.py`
- **Focus**: `BarChart` growing animation and bar highlighting.

## 5. Binary Search Tree (BST)
- **File**: `examples/05_datastructures_bst.py`
- **Focus**: Stateful tree creation, comparison path-traced insertions, and search path animations.

## 6. Sorting Algorithm: Quick Sort
- **File**: `examples/06_algorithms_sorting.py`
- **Focus**: `quick_sort(arr)` executing pivot partition swaps over an `Array` component.

## 7. Graph Pathfinding: Dijkstra
- **File**: `examples/07_pathfinding_dijkstra.py`
- **Focus**: `dijkstra(g, start, target)` shortest-path frontier exploration and final path visualization on a `Graph` component.
